01 / Overview

What it demonstrates

The module exposes a simple device interface at /dev/kmsgbuf. Writes append to the buffer, reads consume data from the front, and writing CLEAR\n empties it.

01

Character devices

Registers a device dynamically and connects standard file operations to kernel code.

02

Safe user access

Uses copy_from_user() and copy_to_user() for transfers across the user/kernel boundary.

03

Synchronization

Protects shared buffer data with a mutex and reports full-buffer writes with ENOSPC.

Learning project

This is an educational example, not a production driver or stable userspace ABI. It does not include poll support, ioctl commands, or persistent storage. Build and test results depend on the Linux kernel and environment used.

03 / Try it

Build and run on Linux

Use a Linux machine or disposable VM with kernel headers matching its running kernel. Loading a kernel module requires appropriate privileges.

Build and load

make
sudo insmod kmsgbuf.ko
dmesg | tail
ls -l /dev/kmsgbuf

Use the device and unload

make client
./kmsgbufctl write 'hello from userspace'
./kmsgbufctl read
./kmsgbufctl clear
sudo rmmod kmsgbuf

If udev does not create /dev/kmsgbuf, follow the manual device-node steps in the README. Test experimental modules in a disposable VM.
