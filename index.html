Kernel Proc Status

A small educational kernel module that creates a read-only /proc/kernel_status entry for selected system information.

View my GitHub Build and usage guide

What it reports

  • Running kernel release
  • Configured kernel timer frequency
  • Number of online CPUs

Kernel concepts

The module demonstrates initialization and cleanup, procfs entry creation, the seq_file interface, and a simple out-of-tree module build. The source targets Linux 5.6 and newer.

Run it

make
sudo insmod kernel_status.ko
cat /proc/kernel_status
sudo rmmod kernel_status

Build and load kernel modules in a disposable Linux VM with headers matching its running kernel.
